1. Run Locally (CMD/CLI)

* Export/download code from AI Studio
* Extract and open folder in CMD
* Install dependencies: `npm install`
* Start app: `npm run dev`
* Open: [http://localhost:3000](http://localhost:3000)

2. Free Hosting (Render)

* Push code to GitHub
* Create account on Render
* Create new Web Service
* Settings:

  * Build: `npm install && npm run build`
  * Start: `npm start`
* Get live URL (e.g., your-app.onrender.com)
